# Образцы

В папке лежат образцы ОБЕИХ версий формата. Файлы `genuine-2.0-*` — формат
2.0: подпись вынесена в отдельную запись `<имя манифеста>.jws`, цепочка
аттестации лежит в её защищённом заголовке. Остальные — формат 1.x, где
подпись стоит полем внутри манифеста.

В репозиторий входят два файла — `genuine.trustvisor` (видео) и
`genuine-photo.trustvisor` (фотография). Это настоящие съёмки настоящими
устройствами, а не собранные вручную примеры: с аппаратной аттестацией,
подписью и разовым вызовом, подтверждённым нашим сервером. Без них нельзя
запустить ни положительные проверки, ни перебор.

Ни в одной из двух съёмок нет координат — ни в манифесте, ни в EXIF кадра.
К работе ядра место съёмки отношения не имеет, а образец из публичного
репозитория живёт долго и расходится широко.

Видео и фотография проверяются разными путями — у видео два манифеста, две
подписи и сверка сессии, — поэтому нужны оба.

Ещё два образца делаются из видео на месте:

```bash
python make_samples.py
```

| файл | что с ним сделано | ожидаемый вердикт |
|---|---|---|
| `genuine.trustvisor` | ничего | ПОДЛИННО |
| `genuine-photo.trustvisor` | ничего | ПОДЛИННО |
| `tampered.trustvisor` | перевёрнут один байт в середине файла | ИЗМЕНЁН |
| `unattested.trustvisor` | вырезано поле `attestationChain` | НЕ АТТЕСТОВАНО |

Производные файлы намеренно не хранятся в репозитории: скрипт короче их и
показывает ровно, что было сделано, — это убедительнее готового файла.

## Почему вырезанная цепочка не ломает подпись

`attestationChain` — одно из трёх полей, которые дописываются в манифест уже
после подписания и в подписанные байты не входят (§3 спецификации). Убрав его,
мы получаем файл с верной подписью и верным хешем, но без аппаратного
подтверждения происхождения. Это ровно то, что случилось бы с настоящей
съёмкой на устройстве без пригодной аттестации.

## Чего эти образцы не заменяют

Перебор в `tools/` портит настоящую съёмку сотнями способов. Четыре файла
здесь — быстрая проверка «работает вообще», а не замена перебору.
